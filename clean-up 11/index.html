```html ล้างไฟล์ขยะ Windows 11
🧹

ล้างไฟล์ขยะ Windows 11

คู่มือทำความสะอาดพื้นที่จัดเก็บข้อมูลอย่างปลอดภัย พร้อมวิธีที่ทำได้ด้วยเครื่องมือใน Windows

⚠️ ก่อนเริ่มล้างไฟล์ แนะนำให้ปิดโปรแกรมที่กำลังใช้งาน และตรวจสอบรายการไฟล์ก่อนกดลบ โดยเฉพาะโฟลเดอร์ Downloads และไฟล์ส่วนตัว
01

🪟 Storage Cleanup

วิธีที่ง่ายและปลอดภัยที่สุด ใช้ระบบจัดการพื้นที่ของ Windows 11

1 เปิด Settings
2 เลือก System
3 เลือก Storage
4 กด Temporary files
5 เลือกไฟล์ที่ต้องการลบ
6 กด Remove files
✓ เหมาะสำหรับผู้ใช้ทั่วไป
02

🧽 Disk Cleanup

เครื่องมือดั้งเดิมของ Windows สำหรับค้นหาและลบไฟล์ชั่วคราว

1 กด Win + R
2 พิมพ์ cleanmgr
3 กด Enter
4 เลือกไดรฟ์ C:
5 เลือกประเภทไฟล์
6 กด OK → Delete Files
✓ ไม่ต้องติดตั้งโปรแกรมเพิ่ม
03

🗑️ ล้าง Temporary Files

ลบไฟล์ชั่วคราวที่โปรแกรมและ Windows สร้างขึ้นระหว่างการใช้งาน

1 กด Win + R
2 พิมพ์ %temp%
3 กด Ctrl + A
4 กด Delete
5 หากไฟล์ไหนลบไม่ได้ ให้กด Skip
✓ ไฟล์ที่กำลังถูกใช้งานอาจลบไม่ได้ เป็นเรื่องปกติ
04

🧹 Windows Temp

ทำความสะอาดไฟล์ชั่วคราวของระบบเพิ่มเติม

1 กด Win + R
2 พิมพ์ temp
3 กด Enter
4 Ctrl + A
5 Delete
6 กด Skip หากระบบถาม
✓ ไฟล์ที่ถูกใช้งานอยู่ไม่จำเป็นต้องฝืนลบ
05

⚡ ล้างไฟล์ด้วยคำสั่ง Windows

สำหรับผู้ใช้ที่ต้องการเปิดโฟลเดอร์ Temp อย่างรวดเร็ว

start %temp%
start temp
💡 คำสั่งเหล่านี้เปิดโฟลเดอร์เพื่อให้คุณตรวจสอบและลบไฟล์เอง ไม่ได้ลบไฟล์ทั้งหมดโดยอัตโนมัติ
06

♻️ Storage Sense

ให้ Windows ช่วยจัดการไฟล์ชั่วคราวแบบอัตโนมัติ

1 เปิด Settings
2 System → Storage
3 เปิด Storage Sense
4 ตั้งค่าการล้างไฟล์ตามต้องการ
✓ เหมาะสำหรับคนที่ไม่อยากมานั่งล้างไฟล์เองบ่อย ๆ
07

🛡️ สิ่งที่ไม่ควรลบแบบสุ่ม

ไม่ควรเข้าไปลบไฟล์ในโฟลเดอร์ระบบโดยไม่รู้ว่าไฟล์นั้นทำหน้าที่อะไร

❌ C:\Windows
❌ C:\Program Files
❌ C:\Program Files (x86)
❌ โฟลเดอร์ของโปรแกรมที่ยังใช้งานอยู่
⚠️ Downloads — ตรวจสอบก่อนลบ เพราะอาจมีไฟล์ส่วนตัว
🔒 ถ้าไม่แน่ใจว่าไฟล์คืออะไร อย่าเพิ่งลบ
Windows 11 Cleanup Guide • ใช้เครื่องมือของ Windows เป็นหลัก
```
